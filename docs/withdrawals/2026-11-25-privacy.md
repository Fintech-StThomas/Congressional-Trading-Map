## Go / no-go on the dry run (check before the real run)

Run with `dry_run` ticked first. Go only if the printed plan shows all of:

- `would_withdraw`: the 10 ids above; `descriptors_found`: 10 (anything less means a mistyped id).
- `exposed_blobs`: 117.
- `live_releases`: at least 1 (the current release); the command itself refuses if the current release is not
  among the live releases the bucket listing found.
- `would_keep_shared_blobs`: at least 1,337 (old holdings blobs shared with the current release, from the scan; the
  real figure should be in the thousands). 0 or a small number means the current release was not seen as live: stop.
- `would_delete_blobs`: at least 287 (old-only holdings blobs alone). Above about 8,000, raise the job's
  `timeout-minutes` first (a timed-out run is finished by re-running the same inputs).

Then run again with identical inputs and `dry_run` unticked, and add both run numbers and printed results here.
